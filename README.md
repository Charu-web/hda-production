# HDA Production Platform

A commercial web platform engineered for HDA Production, supporting client inquiries, media portfolio showcases, dynamic service management, and responsive layouts.

## Overview

HDA Production delivers a fast, media-optimized web experience featuring responsive galleries, inquiry workflows, service breakdowns, and cross-browser accessibility.

## Key Features

- **Media Portfolio Showcase**: Interactive photography & cinematography gallery filters.
- **Client Inquiry Flow**: Structured booking and service inquiry forms.
- **Dynamic Service Management**: Dedicated service landing sections (Corporate, Events, Commercial, Weddings).
- **Responsive Layout**: Fluid CSS grid and flexbox styling optimized for mobile and desktop viewports.

## Tech Stack

- **Frontend**: HTML5, Modern CSS3, JavaScript (ES6+), Bootstrap
- **Assets / Media**: WebP / JPEG media delivery with responsive srcset mapping
- **Tooling**: Node.js, Cheerio

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Charu-web/hda-production.git
   cd hda-production
   ```

2. **Serve locally:**
   Open `index.html` directly in your browser, or use any local static file server:
   ```bash
   npx serve .
   ```
